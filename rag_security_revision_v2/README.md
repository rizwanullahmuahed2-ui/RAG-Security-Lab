# RAG security research evidence

This version contains the completed real-LLM follow-up C, retrospective B source and scoring diagnostics, the author's reported 72-case semantic inspection and preserved historical A context.

Current documents:

- [English article](manuscript/Working_Manuscript_v2.pdf)
- [Dari implementation report](report/Implementation_Report_FA.pdf)
- [Author's semantic findings](manual_review/Author_Semantic_Findings_FA.md)
- [Independent evidence verification](release/GITHUB_EVIDENCE_README_FA.md)

The current evaluation uses a single-author, retrospective, source-based case inspection. It has no outstanding reviewer-recruitment requirement. Automatic target-choice/value outcomes are reported separately from semantic case interpretations; a population factual attack-success percentage is not claimed.

C has 62 fixed questions, 853 distinct payloads, 2559 fresh provider replies across 3 rounds and 5208 condition rows. The complete frozen source, returned vectors, actual contexts, exact requests, raw replies, usage ledger and saved-output analysis are included. Main conclusions use C; B remains retrospective diagnostic material and A historical context. The exact principal/repetition A execution archives remain unrecovered.

Some archived evaluation definitions are retained at their original paths because the experiment hashed them before inference. They preserve the original execution record and do not impose a current reviewer workflow. Do not alter frozen inputs to make a later change appear prospective.

The evidence can be checked without an API key or new model requests. Use the commands in the verification guide. Credentials, local secret files and the virtual environment are excluded from publication. Source-title exclusion is not a guarantee of semantic/source-family or pretraining independence; source-relative inspection is not external fact certification.
