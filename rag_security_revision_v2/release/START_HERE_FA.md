# راهنمای نسخهٔ جاری

این نسخه شامل مقاله، گزارش تطبیق۶۷مورد، یافته‌های بررسی دستی معنایی نویسنده و شواهد کامل آزمایش است. روش جاری بر نتایج واقعی C و بررسی موردی۷۲پاسخ تکیه دارد. B برای بازتحلیل و تشخیص مسئلهٔ مرجع و A فقط برای زمینهٔ تاریخی حفظ شده‌اند.

برای متخصص، لینک صفحهٔ اصلی GitHub ارسال شود. مقاله، گزارش، یافته‌ها و راهنمای بررسی مستقل از همان صفحه قابل دسترس‌اند. برای تطبیق پاسخ‌های خام، هش‌ها،۲٬۵۵۹فراخوانی و۵٬۲۰۸ردیف، دستور راهنمای `GITHUB_EVIDENCE_README_FA.md` اجرا شود؛ کلیدAPIیا اجرای تازهٔ مدل لازم نیست.

نتیجهٔ عددی آزمایش منجمد تغییر نکرده است. یافتهٔ تازه و مستند، تفکیک معنای ادعا، قید، امتناع و پشتیبانی واقعی در نمونهٔ۷۲موردی است. این نمونه به‌عنوان درصد دقت کل سیستم یا موفقیت معنایی تمام حملات معرفی نمی‌شود. عیب‌های مرجعBو نبود آرشیو دقیقA نیز با محدودیت خود گزارش شده‌اند.
